# Semantic Model: realtime-operational-model

DirectQuery semantic model over the Eventhouse, backing the operational Power BI dashboard.
Row-Level Security scopes users to their facility; Object-Level Security hides
controlled-substance columns from non-compliance roles.

Not yet written — this is largely authored/maintained via the Fabric UI or `fab`/`fabric-cicd`
rather than Terraform, per the plan's provider-coverage notes.
